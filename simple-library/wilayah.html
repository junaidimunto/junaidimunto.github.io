  <option>Silahkan pilih kecamatan</option>

<script src="https://cdn.jsdelivr.net/gh/junaidimunto/simple-library@4036918/Wilayah.js"></script>
<script>
  const wilayah = new Wilayah("the-province", "the-regency", "the-district", "the-village");
  wilayah.performFetchingProvinces();
  wilayah.performChangingSelect();
</script>
Notes:
  1. This minimalist tag <select id="the-id"></select> will automatically create attribute name="the-id" identic to the id, but not if was defined before.
  2. The instance Wilayah() has 4 optional parameters that contains selector id for province, regency, district, and village, respectively. Leaving it blank will automaticalaly create id and name provinceSelect, regencySelect, districtSelect, and villageSelect, respectively.
  3. The function performFetchingProvinces() should be explicitly called to fetch initial provinces list option.
  4. The function performChangingSelect() should be explicitly called to add event listener "change" for each selects.

Print selects by js


<div class="some-classes">
  <script src="https://cdn.jsdelivr.net/gh/junaidimunto/simple-library@4036918/Wilayah.js"></script>
  <script>
    const wilayahku = new Wilayah("theProvince", "theRegency", "theDistrict", "theVillage");
    wilayahku.printProvinceSelect("Pilih Provinsi", "your-class form-select mb-2", "required");
    wilayahku.printRegencySelect("Pilih Kabupaten/Kota", "form-select mb-2", "required");
    wilayahku.printDistrictSelect("Pilih Kecamatan/Distrik", "form-select mb-2", "required");
    wilayahku.printVillageSelect("Pilih Desa/Kelurahan", "form-select mb-2");
    wilayahku.performChangingSelect();
  </script>
<div>
Notes:
  1. The instance Wilayah() has 4 optional parameters that contains selector id for province, regency, district, and village, respectively. Leaving it blank will automaticalaly create id and name provinceSelect, regencySelect, districtSelect, and villageSelect, respectively.
  2. The function performChangingSelect() should be explicitly called to add event listener "change" for each selects.
